## English

- Fix GIF conversion and video speed export failing on some Windows library paths with “The network path was not found.”
- Add shortcuts in Settings → About to open the settings, logs, error logs, and temporary folders, plus the GitHub repository.
- Remove the repeated manual-update description in Windows Portable and Linux settings.

Thanks to @yuxino for the changes and @az6161311 for reporting the issues and suggestions.

Update through Settings on macOS and installed Windows. Windows Portable users can replace their app with the new ZIP; Linux users can install with `sudo apt install ./kiri_1.6.21_amd64.deb`. Existing library and AppData locations are unchanged.

macOS uses Kiri's stable local signing identity and is not Apple-notarized; Windows packages are not Authenticode-signed.

## 中文

- 修复 Windows 部分素材库路径下转换 GIF、变速导出视频时提示“找不到网络路径”的问题。
- 在设置 → 关于中增加设置、日志、错误日志和临时目录的快捷入口，以及 GitHub 仓库链接。
- 去掉 Windows 便携版和 Linux 设置中重复的手动更新说明。

感谢 @yuxino 完成本次改动，也感谢 @az6161311 提供问题反馈和建议。

macOS 和 Windows 安装版可在设置中更新；Windows 便携版请下载新 ZIP 替换程序。Linux 请运行 `sudo apt install ./kiri_1.6.21_amd64.deb`。原有素材库和 AppData 路径保持不变。

macOS 沿用 Kiri 的稳定本地签名，未经 Apple 公证；Windows 安装包没有 Authenticode 签名。
