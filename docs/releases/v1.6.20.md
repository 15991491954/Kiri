## English

- Keep the recording controls beside the selected region and show an outline around that region on supported macOS and Windows systems.
- Simplify recording setup and add a microphone device menu. Recording starts after a three-second countdown.
- Recognize floating windows such as Mimi subtitle panels when selecting a window on macOS.
- Fix Windows screenshot captures retaining the library window, improve dragging pinned screenshots, and refine their black frame.
- Simplify the README and documentation layout.

Thanks to @yuxino for the changes and @az6161311 for the recording feedback.

Update through Settings on macOS and installed Windows. Windows Portable users can replace their app with the new ZIP; Linux users can install with `sudo apt install ./kiri_1.6.20_amd64.deb`.

Windows may retain its system recording indicator when borderless capture is unavailable or not permitted. Linux recording continues to use tray controls. macOS uses Kiri's stable local signing identity and is not Apple-notarized; Windows packages are not Authenticode-signed.
